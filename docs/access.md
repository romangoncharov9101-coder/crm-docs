# Доступы: пользователи, роли, команды
Раздел администратора.
 
**Пользователи** — учётные записи, у каждой роль. Отключённый пользователь не входит в систему и не получает оповещений.
**Роли** — здесь настраивается, что можно делать. Для каждой сущности отдельно:
| Права на записи | Что значит |
|---|---|
| **C** | Создание |
| **R** | Просмотр |
| **U** | Изменение |
| **D** | Удаление |
 
Дополнительно по каждой сущности:
- **Просмотр логов** — история изменений на карточке;
- **Импорт**, **Экспорт**, **Массовое изменение**;
- **Комментарии**: просмотр/создание, редактирование своих, редактирование любых, удаление;
- **Видеть все** — снимает ограничение видимости по командам.
Права можно раздавать и **по отдельным полям** — какие поля роль видит, а какие может менять. При создании нового поля роли с доступом к сущности получают права на него автоматически.
 
**Команды** — определяют, чьи записи вы видите. Общая логика:
- у записи есть команда её создателя (запись без команды считается общей и видна всем, у кого есть доступ к сущности);
- вы видите записи своих команд;
- руководитель видит ещё и все подчинённые команды, рекурсивно;
- при включённой сквозной видимости — ещё и соседние команды с их подкомандами;
- пользователь вне команд видит только общие записи;
- право Видеть все отменяет эти ограничения.
Важно: цифры на виджетах и в календаре считаются по этим же правилам, поэтому у разных сотрудников они могут отличаться.
 
**Журнал действий** — кто, что и когда менял в системе.
