# Первый вход и общий интерфейс
После входа вы попадаете на **Дашборд** - страницу с виджетами (цифры и графики).
В верхней панели:

- **Дашборд** - сводные показатели;
- **Названия ваших сущностей** - переход к спискам записей;
- **Поиск** - ищет по всем сущностям сразу, результаты сгруппированы по разделам;
- **Значок солнца/луны** - светлая и темная тема;
- **Ваше имя** - личные настройки;
- **Администрирование** - пользователи, команды, роли, журнал действий, виджеты;
- **Сущности** - управление разделами и полями.

### Личные настройки

- **Открывать запись в новой вкладке** - при клике по строке список с фильтрами и прокруткой остается на месте, запись открывается рядом. Без галочки запись откроется в той же вкладке;
- **Темная тема** - выбор запоминается в этом браузере. Если ничего не трогать, берется настройка операционной системы.
