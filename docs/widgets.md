# Виджеты (главный раздел)
Виджет — это одна цифра или один график, посчитанный по вашим данным. Настраивается администратором в **Администрирование → Виджеты**, либо кнопкой **+ Виджет** прямо на странице сущности.
 
### 8.1. Обязательное условие
**Поле попадает в конструктор виджетов только с галочкой "Использовать на дашборде".** Если в выпадающих списках конструктора нет нужного поля — вернитесь в настройки поля и поставьте эту галочку.
 
### 8.2. Где виджет живёт: место размещения
- **Дашборд** — виджет на главной странице.
- **Страница сущности** — виджет виден только над списком записей этой сущности. Такой виджет получается, если создавать его кнопкой + Виджет со страницы сущности; источник данных там уже зафиксирован и не переключается.
В разделе Виджеты всё сгруппировано: сначала группа Дашборд, затем группы по сущностям. Внутри группы каждый виджет можно **включить/выключить**, **изменить** или **удалить**.
Выключенный виджет исчезает с экрана, но продолжает считаться — его значение остаётся доступно формулам. Это удобно: держите технические слагаемые выключенными и показывайте только итог.
 
### 8.3. Поля конструктора
**Название** — подпись виджета.
**Ключ** — техническое имя латиницей, подставляется само из названия. По ключу на виджет ссылаются формулы: `{ключ}`. После создания ключ не меняется.
**Метрика** — что виджет считает:
- *Агрегация по сущности* — обычный подсчёт по данным.
- *Формула над виджетами* — арифметика над значениями других виджетов.

**Отображение:**
| Тип | Как выглядит |
|---|---|
| **Число** | Крупная цифра в карточке |
| **Столбцы** | Столбчатая диаграмма во всю ширину |
| **Кольцо** | Круговая диаграмма с легендой и значениями |
| **Список** | Горизонтальные полоски со значениями (рейтинг) |
| **График** | Плавная линия с точками и шкалой |
 
**Формат значения:**
- *Число* — обычное число;
- *Деньги* — с денежным форматированием;
- *Проценты* — доля от всех видимых записей сущности. Доступен только при агрегации Количество записей.
**Сущность** — откуда берутся данные.
 
**Агрегация:**
| Агрегация | Что считает | Требует поле |
|---|---|---|
| Количество записей | Сколько строк подошло | нет |
| Сумма | Сложение значений | да, только Деньги |
| Среднее | Среднее значение | да, только Деньги |
| Минимум / Максимум | Крайние значения | да, только Деньги |
| Уникальных значений | Сколько разных значений | да, любое поле с галочкой дашборда |
 
**Группировать по** (только для графиков) — разрез. Два вида:
 
*По времени:*
- **По дням** — отрезки по дням;
- **По неделям** — подпись вида 17.08 – 23.08;
- **По месяцам** — всегда рисуются все 12 месяцев текущего года. Прошедшие месяцы без данных — тонкая полоска на нуле, будущие — тонкая серая. Так график читается как календарь и не прыгает.
Разрез по времени требует, чтобы ниже было выбрано **поле даты**.
 
*По полю:* поля типа Список и Связь с галочкой дашборда, плюс системное Ответственный.
 
**Поле даты и Период.** Поле даты — Дата создания, Дата изменения или любое ваше поле типа Дата с галочкой дашборда. Период: Сегодня, Вчера, 7 дней, 30 дней, Текущий месяц, Прошлый месяц, Текущий год, Прошлый год. Без периода считается за всё время. Период без указанного поля даты работать не будет.
 
**Условия (фильтры).** Любое число условий, все складываются по И. Операторы: `=`, `!=`, `>`, `>=`, `<`, `<=`, `contains` (содержит), `is_null` (пусто), `not_null` (заполнено). Для полей-списков значение выбирается из выпадающего списка.
 
Особый тип условия — **Количество: <Сущность> (<поле>)**. Это количество связанных записей, ссылающихся на текущую. Здесь доступны только числовые сравнения. Примеры:
- `= 0` — записи, у которых нет ни одной связанной;
- `> 0` — есть хотя бы одна;
- `>= 3` — три и больше.
**Кому виден** — отметьте роли. Пусто = виден всем, у кого есть доступ к сущности-источнику.
 
### 8.4. Формулы
Метрика Формула над виджетами. В поле формулы ссылайтесь на ключи других виджетов в фигурных скобках.
Правила:
- допустимы числа, скобки и `+ - * /`, а также `NULLIF(a, b)` (защита от деления на ноль);
- ссылаться можно только на виджеты-агрегации, не на другие формулы;
- на самого себя ссылаться нельзя;
- отображается только числом;
- формулу нельзя разместить на странице сущности — только на дашборде.
Примеры:
 
```
{deals_won_sum} - {deals_lost_sum}
{deals_won_count} / NULLIF({deals_total_count}, 0) * 100
({revenue} - {costs}) / NULLIF({revenue}, 0) * 100
```
 
### 8.5. Кликабельность
Почти всё в виджетах кликабельно и уводит в список записей с уже наложенным фильтром:
- сегмент кольца, полоска списка, столбец, точка графика — фильтр по этой группе или периоду;
- числовой виджет с условием Количество связанных записей — фильтр по этому условию.
Если в списке после такого перехода записей меньше, чем ожидалось, вверху горит плашка **Фильтр виджета активен** — сбросить его можно кнопкой Сбросить.
 
### 8.6. Права и корректность цифр
- Виджет считает только те записи, которые **вы имеете право видеть**. У разных сотрудников одна и та же карточка может показывать разные числа — это правильно.
- Если у роли нет доступа к сущности-источнику, виджет просто не отображается.
- Проценты считаются от общего числа записей за тот же период, а не от суммы сегментов, — иначе диаграмма с фильтром всегда давала бы 100%.
- Виджеты обновляются вживую: если коллега создал запись, цифры пересчитаются без перезагрузки страницы.
### 8.7. Примеры настройки
 
**Пример 1. Клиентов за месяц — простая цифра**
```
Название:        Новые клиенты за месяц
Метрика:         Агрегация по сущности
Отображение:     Число
Формат:          Число
Сущность:        Клиенты
Агрегация:       Количество записей
Поле даты:       Дата создания
Период:          Текущий месяц
Условия:         —
```
 
**Пример 2. Сделки по статусам — кольцо**
```
Название:        Сделки по статусам
Отображение:     Кольцо
Сущность:        Сделки
Агрегация:       Количество записей
Группировать по: Статус  (поле-список, галочка дашборда обязательна)
Период:          Текущий год  (поле даты: Дата создания)
```
Клик по сегменту откроет сделки этого статуса.
 
**Пример 3. Выручка по месяцам — столбцы**
```
Название:        Выручка по месяцам
Отображение:     Столбцы
Сущность:        Сделки
Агрегация:       Сумма
Поле метрики:    Сумма сделки  (тип Деньги)
Группировать по: По времени → По месяцам
Поле даты:       Дата закрытия
Условия:         Статус = Успешно
```
Будут нарисованы все 12 месяцев года.
 
**Пример 4. Клиенты без сделок — цифра с условием по связям**
```
Название:        Клиенты без сделок
Отображение:     Число
Сущность:        Клиенты
Агрегация:       Количество записей
Условия:         Количество: Сделки (Клиент)  =  0
```
Клик по карточке откроет список именно этих клиентов.
 
**Пример 5. Конверсия — формула**
 
Сначала два вспомогательных виджета-агрегации (их можно **выключить**, чтобы не занимали место):
```
Виджет A: ключ deals_won   — Сделки, Количество записей, Статус = Успешно
Виджет B: ключ deals_total — Сделки, Количество записей, без условий
```
Затем итоговый:
```
Название:    Конверсия, %
Метрика:     Формула над виджетами
Формула:     {deals_won} / NULLIF({deals_total}, 0) * 100
Отображение: Число
```
 
**Пример 6. Нагрузка по сотрудникам — список**
```
Отображение:     Список
Сущность:        Заявки
Агрегация:       Количество записей
Группировать по: Ответственный
Период:          30 дней (поле даты: Дата создания)
```
 
**Пример 7. Виджет на странице сущности**
 
Откройте список Сделки → **+ Виджет**. Источник данных уже зафиксирован на сделках, переключить его нельзя. Такой виджет появится только над списком сделок и на общий дашборд не попадёт.

### 8.8. Ограничения и подсказки 
- Сумма, среднее, минимум и максимум считаются **только по полям типа Деньги**.
- Графику обязательно нужен разрез — без него он не сохранится.
- Формат Проценты доступен только при агрегации Количество записей.
- Обычная группировка показывает до 30 самых крупных значений, разрез по времени — до 400 отрезков.
- Виджет с ключом, на который ссылается формула, **удалить нельзя** — система назовёт мешающие формулы.
- На справочниках виджеты не показываются: это списки значений, аналитика по ним смысла не имеет.
- Если виджет показывает Нет данных, проверьте: правильный период, поле даты заполнено в записях, условия не противоречат друг другу.
