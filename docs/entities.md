# Создание сущностей
Доступно Администратору.

### Быстрый способ
В верхней панели рядом с меню "Администрирование" есть кнопка **"+"**. Откроется окно:
1. **Название** - по-русски, например "Клиенты". Техническое имя-ключ `klienty` система формирует сама транслитерацией.
2. **Тип** - обычная сущность или справочник.
3. **Роли** - отметьте, каким ролям сразу дать доступ. Они получат права на записи (создание, просмотр, изменение, удаление), а также импорт, экспорт и массовое редактирование.

Что происходит автоматически при создании:
- создается таблица данных;
- Появляется обязательное поле **Название** - это заголовок записи.
- появляется поле **Ответственный**
- у основных сущностей появляется поле **Дата создания** и включаются комментарии.

### Раздел "Сущности"
Здесь список всех таблиц. Для каждой:
- **стрелка слева** - развернуть список полей;
- **открыть** - перейти к записям;
- **Редактировать** - изменить название или переключить обычная/справочник;
- **+ Добавить поле** - создать новое поле;
- у каждого поля - Изменить и Удалить.

При удалении сущности удаляется вся таблица со всеми записями, комментариями, правами и сохраненными фильтрами. Действие необратимо.
При смене типа: переключение Справочник -> Основаня безопасно, таблица комментариев досоздается. Обратное переключение тоже обратимо, данные не теряются.
