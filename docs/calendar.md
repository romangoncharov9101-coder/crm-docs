# Календарь и активности
 
### 9.1. Как включить
Календарь — отдельный раздел, но работает поверх обычной сущности. Чтобы он появился:
 
1. Создайте сущность и назовите её **Активности**.
2. Добавьте в неё поле типа **Дата и время** — оно станет началом события.
Всё. Пункт Календарь появится в меню сам, у всех, кто имеет право просматривать эту сущность. Пока сущности нет, страница календаря открывается и вежливо объясняет, что нужно сделать, а не выдаёт ошибку.
 
### 9.2. Как календарь понимает поля
Система смотрит не на названия, а на типы, поэтому поля можно называть как угодно:

| Что нужно календарю | Откуда берётся |
|---|---|
| Заголовок события | Поле Название сущности |
| Начало | **Первое** поле типа Дата и время |
| Окончание | **Второе** поле типа Дата и время (если есть) |
| Тип активности | Поле-список или поле-связь: сначала помеченное как источник плашек, потом названное Тип / Вид, потом список с цветами, потом любой список, потом связь на справочник |
 
### 9.3. Цвет события
Приоритет, как в Google Календаре — личный цвет важнее общего:
1. поле типа **Цвет** у самой записи;
2. цвет связанной записи (например, справочник типов, где у каждого типа задан цвет);
3. цвет варианта в поле-списке Тип активности;
4. цвет по умолчанию.
Цвет текста подбирается автоматически: на светлых фонах (жёлтый, бирюзовый) текст становится тёмным, чтобы читался.
 
### 9.4. Работа с календарём
- Виды: **Месяц**, **Неделя**, **День**. Кнопки назад / вперёд / сегодня.
- **Плашки типов** сверху: и фильтр, и сводка. Счётчики считаются по видимому периоду — сколько звонков имеет смысл именно для месяца или недели на экране. Переключение типов мгновенное, сетка не мигает.
- Выбранные типы **сохраняются в адресе страницы**: можно обновить страницу и ничего не потерять, а ссылку — отправить коллеге.
- Кнопка **Таблица** переносит текущий выбор типов на страницу активностей — фильтр там будет тот же.
- **Клик по дню** открывает создание активности с уже подставленной датой (на 9:00).
- **Клик по событию** открывает карточку (в новой вкладке или в текущей — по вашей настройке).
- Календарь **обновляется вживую**: изменения коллег появляются без перезагрузки.

### 9.5. Настройки календаря (шестерёнка, только администратор)
Здесь выбираются сущности, с которыми связываются активности. Для каждой отмеченной сущности в активностях автоматически появляется поле-связь — например, чтобы к встрече прикрепить клиента или сделку. Снятие галочки удаляет это поле.
Поля, созданные администратором вручную, механизм не трогает — только свои.
Доступны все сущности, включая справочники (они показаны отдельной группой). Нельзя связать активности сами с собой.
