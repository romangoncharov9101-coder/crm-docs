# Оповещения
 
### 10.1. Когда они работают
Оповещения завязаны на **поле исполнителей** (см. 4.4). Если ни в одной сущности такого поля нет, механизм не работает.
Уведомления получают **исполнители записи**. Автор действия себе оповещение не получает.
 
### 10.2. Какие бывают
| Тип | Когда приходит |
|---|---|
| **Назначение исполнителем** | Вас добавили в исполнители записи |
| **Снятие с работы** | Вас убрали из исполнителей |
| **Изменение записи** | Кто-то изменил запись, где вы исполнитель. В тексте перечислены изменённые поля (до восьми) |
| **Новые комментарии** | В записи, где вы исполнитель, появился комментарий (с началом текста) |
 
Отдельное оповещение приходит при **удалении** записи, где вы были исполнителем.
 
### 10.3. Колокольчик
- **Красный счётчик** — число непрочитанных. Он же дублируется в заголовке вкладки браузера, чтобы было заметно на другой странице.
- Клик открывает список: тип, кто сделал, сколько времени назад.
- Клик по оповещению открывает соответствующую запись.
- **Прочитать все** — обнулить счётчик.
- Оповещения приходят **мгновенно**, без перезагрузки страницы.

### 10.4. Настройки оповещений (шестерёнка в колокольчике)
Каждый пользователь настраивает для себя. Можно отключить любой из четырёх типов:
- Назначение исполнителем
- Снятие с работы
- Изменение записи
- Новые комментарии
По умолчанию включено всё. Отключённый тип просто не создаётся — старые оповещения остаются.
Оповещения не приходят отключённым пользователям.
