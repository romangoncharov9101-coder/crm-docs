# Горячие клавиши
Работают в списке записей. **В поле ввода не срабатывают** — печатать можно спокойно. Исключение — Esc, он работает везде.
Список всегда доступен по сочетанию клавиш **`Shift + ?`**.
 
### Навигация
| Клавиша | Действие |
|---|---|
| `↑` `↓` (или `k` `j`) | Перейти между строками |
| `Enter` | Открыть карточку активной записи |
| `Esc` | Снять выделение / закрыть окно |
 
### Выделение
| Клавиша | Действие |
|---|---|
| `Space` | Выделить активную строку |
| `Shift` + клик | Выделить диапазон строк |
| `Ctrl/⌘` + `A` | Выделить всё на странице |
 
### Действия
| Клавиша | Действие |
|---|---|
| `N` | Создать запись |
| `Ctrl/⌘` + `E` | Редактировать активную строку |
| `Ctrl/⌘` + `Delete` | Удалить выделенные (или активную) |
| `Ctrl/⌘` + `I` | Открыть импорт |
| `Ctrl/⌘` + `Shift` + `E` | Экспорт в XLSX (сразу, с текущими фильтрами) |
 
### Поиск и фильтры
| Клавиша | Действие |
|---|---|
| `/` или `Ctrl/⌘` + `K` | Фокус в поиск (панель фильтров развернётся сама) |
| `Ctrl/⌘` + `Shift` + `F` | Показать / скрыть фильтры |
| `Ctrl/⌘` + `Backspace` | Сбросить фильтры |
| `1` … `9` | Сортировать по N-й видимой колонке |
| `?` | Шпаргалка по клавишам |
 
`Ctrl/⌘ + F` и `Ctrl/⌘ + N` намеренно не перехватываются — это поиск браузера и новое окно.
