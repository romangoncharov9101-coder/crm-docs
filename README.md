Исходники сайта документации. Сам сайт собирается автоматически при пуше в `main`.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.md` | Главная страница |
| `docs/*.md` | Разделы руководства, по одному файлу на раздел |
| `_config.yml` | Настройки сайта: название, адрес, тема, поиск |
| `_sass/color_schemes/wiredcrm.scss` | Своя цветовая схема |
| `.github/workflows/pages.yml` | Автоматическая сборка и публикация |

## Как отредактировать текст

Проще всего прямо на GitHub: открыть нужный файл в `docs/`, нажать карандаш,
поправить, нажать «Commit changes». Через минуту-две сайт обновится сам.

## Порядок разделов в меню

Задаётся полем `nav_order` в шапке файла. Меньше число — выше в меню.

## Локальный просмотр (необязательно)

```bash
bundle install
bundle exec jekyll serve
```

Сайт откроется на http://localhost:4000
